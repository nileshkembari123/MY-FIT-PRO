# MY-FIT-PRO

NILESH FITNESS PRO is a mobile-first Progressive Web App for workout plans, meal guidance, habit tracking, and progress logs.

## Deploy on Render
- Create a Render Static Site connected to this repository.
- Branch: `main`
- Build command: leave empty
- Publish directory: `.`

## Install on Android
Open the deployed HTTPS site in Chrome, tap the three-dot menu, then choose **Install app** or **Add to Home screen**.

Progress and habit data are stored locally in the browser on this device. This first version does not sync data across devices.
